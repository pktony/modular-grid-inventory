01

제품 경계

고객에게 제공

  • 격자 이동·회전, 독립 포켓, 유형별 수납 정책.
  • 가방 중첩, 창 이동·재사용·전면 순서, 스택 합치기·분할.
  • SO 편집·즉시 미리보기·Undo/Redo, 효과음 설정.
  • 테마 설정·입력·초기 상태 주입, 공개 API·영문 안내.

개발 환경이 소유

  • Unity MCP, 빌드·녹화·FFmpeg·자동 시연 도구.
  • 게임 원본 리그 이미지·이름·원본 URL 기록.
  • 테스트 실행 도구와 원시 결과.
  • 저장·전투·UI Toolkit·모바일·콘솔 확장은 이번 범위 밖.

현재 구현: InventoryBootstrapper·초기 상태 빌더·입력 어댑터·불변 테마·프리팹·범용 편집기. 중립 아이콘 19종과 후보 아카이브 준비. 컴파일·정적 검사 통과 / Unity 실행 검증 대기.

04

검증 행렬

호환성

  • Unity 6000.0 LTS / 6000.6.4f1 후보.
  • 두 버전 URP 필수; Built-in은 별도 통과 후 표기.
  • Legacy · Both · Input System only.

현재 설치: 6000.6.4f1만. 검증 전 지원 버전을 광고하지 않는다.

수명과 설치

  • Domain Reload 켬/끔, Play 반복 10회.
  • 최초·재임포트·업그레이드·경로 이동.
  • 사용자 SO·ProjectSettings·기존 씬 보존.

Missing 참조와 리스너·창·AudioSource 누적 0.

기능과 공개 API

  • 중첩·순환·독립 포켓·스택·실패 불변.
  • 다중 창·회전·수납 두 경로·오디오.
  • 모델 전용 예제·범용 Inspector·Undo/Redo.

현재 기준: Edit 91 / Play 24 / Windows 27 / 녹화 49. 패키지 이동 후 재검증.
