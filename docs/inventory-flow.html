타르코프식 인벤토리 완성 계획

격자 배치 규칙과 조작의 완성도를 보여주는 하나의 기능 데모.

요청: “포트폴리오를 위한 또 재미를 위해 타르코프라는 게임의 인벤토리 시스템 단일 기능만 만든 것.”

계획 본문 PLAN.md · 본문과 같은 범위·순서·완료 기준을 시각화합니다.

01

완성 범위

하나의 인벤토리를 끝까지

다른 크기의 아이템 추가 → 선택 → 이동 → 회전 → 삭제 → 초기화.

드래그 이미지, 배치 가능/불가 표시, 툴팁과 조작 안내를 포함합니다.

구현: 9×20 격자, 180칸, 테스트 아이템 7개. Unity 6000.6.4f1.

후속 확장

저장·불러오기, 다중 인벤토리, 스택·분할, 가방 중첩.

핵심 단계 완료 후 선택합니다. 전체 게임 기능은 범위 밖입니다.

02

검토 가능한 마일스톤

STEP 01

배치 모델 안정화

모델검증

추가·이동·회전·삭제 API와 점유 셀에서 아이템을 찾는 규칙.

통과: 겹침·경계·공간 부족 거절, 실패 시 데이터 불변, 자기 영역 이동·회전 허용.

STEP 02

화면 구조 정리

UI씬

UI 단일 연결, 셀과 아이템 계층 분리, 생성·갱신·정리 절차.

통과: 180칸·7개 아이템 표시, 빈 칸 클릭 무오류, 재초기화 중복 없음.

STEP 03

드래그 이동

입력모델UI

잡은 칸 기억, 포인터 좌표 변환, 드래그 이미지, 배치 미리보기·확정·취소.

통과: 어느 점에서 잡아도 위치 유지, 성공 시 한 번 이동, 겹침·바깥 드롭·Esc 시 원상 유지.

STEP 04

회전과 기본 편집

입력모델UI

R 회전, 선택·Delete 삭제, 추가·초기화 데모 버튼.

통과: 1×1·2×1·4×2·5×1 조작, 회전 재검사, 삭제 후 전체 점유 해제, 공간 부족 안내.

STEP 05

조작감과 표시 마감

UI데이터

툴팁·호버·선택·초록/빨강 미리보기, 아이템 정의 데이터, 조작 안내.

통과: 이미지 누락 없음, 1280×720·1920×1080 좌표 일치, 스크롤 중 드래그 정책 일관.

STEP 06

포트폴리오 패키징 · 직접 조작 검증 대기

검증빌드문서

모델 테스트, 플레이 시나리오, Windows 빌드, README, 60~90초 영상.

완료: 빌드·README·60초 영상 생성. 남음: Windows 빌드 직접 조작 검증.

03

입력에서 확정까지

원본과 미리보기를 분리합니다. 아이템 정의·리소스를 준비한 뒤 배치 검증과 상태 확정은 동기 처리합니다.

04

시연 화면의 두 상태

A / 배치 가능

초록 영역: 드롭 시 확정. R로 방향을 바꿔 다시 검사합니다.

B / 배치 불가

빨강 영역: 드롭 거절. 바깥 드롭이나 Esc도 원본을 유지합니다.

상태 설명용 목업입니다. 실제 UI는 어두운 개발 데모 스타일로 마감했습니다.

05

위험과 완화

위험심각도완화

회전 기준점 어긋남높음잡은 위치 정의, 회전 전후 포인터 기준 검증

06

완료 증거와 남은 선택

리뷰어가 확인할 결과

  • Windows 빌드 생성 · README 조작 안내
  • 배치·입력 실패 경로를 포함한 검증 결과
  • 다른 크기 소개 → 이동 → 회전 → 거절 → 취소 → 삭제·추가 → 초기화 시연
  • 모델·입력·UI 구조, 설계 결정, 이미지 출처와 사용 조건

선택과 후속 작업

  • 어두운 개발 데모 스타일
  • 드래그 중 휠 스크롤; 자동 스크롤은 후속 개선
  • 공개 빌드의 이미지 사용 조건 확인·교체 여부

자동 테스트 20개 통과. Windows 빌드의 드래그 입력 호환 확인은 남아 있습니다.
