## Generated project resources

The 19 PNG icons in `Samples/Icons` were generated for this project using OpenAI's built-in imagegen tool on 2026-10-07. Prompts requested fictional expedition equipment without brands, existing game imagery or real product references. Source PNGs retain transparency; Unity importer settings cap runtime texture size at 512. Selected prompts, optional edit instructions, dimensions and SHA-256 hashes are recorded in `GeneratedAssets.json`.

Codex assisted with source code, package organization, documentation and test authoring. No game's original icons are included in this package. Earlier reference footage and research remain outside the exported asset root.
