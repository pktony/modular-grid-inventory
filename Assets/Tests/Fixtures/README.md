# Audio test fixtures

These assets exercise the optional audio extension. They are outside `Assets/ModularGridInventory` and must not be exported with the product. The default scene and prefab remain silent.

The 21 clips originate from Kenney Interface Sounds 1.0 and Impact Sounds 1.0 under CC0. Their license files remain in `Audio/Interface` and `Audio/Impact`. The clips were decoded to PCM16 WAV with peak limiting below -1 dBFS; conversion does not restore information lost in the original encoding. Asset GUIDs were preserved during relocation.
